# Library Automation Management System

## Project Description
The Library Automation Management System is a simple application
that helps manage books in a library.

## Features
- Add new books
- Search books by title or author
- Borrow books
- Return borrowed books
- Display available books

## Technologies
- JavaScript
- Node.js
- Git
- GitHub
- Jenkins

## Run the Application
node src/library.js

## Run Tests
npm.cmd test
